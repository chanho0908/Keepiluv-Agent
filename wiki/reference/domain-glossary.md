# Keepiluv Domain Glossary

이 문서는 Keepiluv의 기획, 문서, 테스트, 코드 리뷰에서 같은 개념을 같은 언어로 설명하기 위한 공식 도메인 용어집입니다.

현재 코드와 팀에서 확인한 도메인 정책을 기준으로 작성했습니다. 새롭게 발견된 미확정 항목은 공식 용어와 분리해 **검토 필요**로 표시합니다.

## 사용 원칙

테스트 이름, 계획서, PR 설명에는 이 문서의 **공식 용어**를 사용합니다. 코드 변수명이나 클래스명을 번역해 새로운 용어를 만들지 않습니다.

## 사용자와 커플

### 사용자

앱에 로그인한 개인 계정입니다.

- 공식 용어: `사용자`
- 현재 로그인한 사용자를 가리킬 때: `나`, `내 정보`
- 코드 표현: `User`, `userId`, `users/me`
- 사용 예: `사용자 정보를 조회한다`, `내 인증샷을 표시한다`
- 피할 표현: 문맥 없는 `유저`, `본인`

### 짝꿍

현재 사용자와 커플로 연결된 상대방입니다.

- 공식 용어: `짝꿍`
- 코드 표현: `partner`, `partnerNickname`, `BetweenUs.PARTNER`
- 화면 표현: `짝꿍`, 일부 화면의 `%s님`
- 사용 예: `짝꿍의 인증샷`, `짝꿍과 연결한다`
- 피할 표현: 사용자와 도메인 행위를 설명할 때 사용하는 `파트너`, `메이트`

### 커플 연결

초대 코드를 사용해 두 사용자를 하나의 커플 관계로 연결하는 과정입니다.

- 공식 용어: `커플 연결`
- 코드 표현: `coupleConnection`, `ConnectCouple`, `COUPLE_CONNECTION`
- 관련 개념: 초대 코드, 상대방
- 사용 예: `초대 코드로 짝꿍과 커플 연결을 완료한다`
- 피할 표현: 관계 복구와 혼동되는 `커플 등록`

### 초대 코드

커플 연결에 사용하는 코드입니다. 사용자는 자신의 코드를 공유하거나 짝꿍에게 받은 코드를 입력합니다.

- 공식 용어: `초대 코드`
- 코드 표현: `InviteCode`, `inviteCode`, `myInviteCode`, `partnerInviteCode`
- 제약: 공백을 제외한 8자리
- 사용 예: `짝꿍에게 받은 초대 코드를 입력한다`
- 피할 표현: 화면에 남아 있는 `조회코드`, 의미가 다른 `연결 코드`

### 프로필

짝꿍에게 표시할 사용자의 닉네임 정보입니다.

- 공식 용어: `프로필`
- 핵심 값: `닉네임`
- 코드 표현: `Profile`, `NickName`, `nickname`, `PROFILE_SETUP`
- 제약: 2자 이상 8자 이하

### 기념일

커플이 함께 사용하는 기준 기념일입니다.

- 공식 용어: `기념일`
- 코드 표현: `anniversary`, `Dday`, `ANNIVERSARY_SETUP`
- 사용 예: `우리의 기념일을 등록한다`

## 목표

### 목표

커플이 함께 반복해서 수행하기로 정한 활동입니다.

- 공식 용어: `목표`
- 코드 표현: `Goal`, `GoalDetail`, `GoalSummary`, `goalId`
- 주요 속성: 이름, 아이콘, 반복 주기, 반복 횟수, 시작일, 종료일
- 사용 예: `새 목표를 만든다`, `선택한 목표 날짜의 목표를 조회한다`

### 목표 이름

목표를 식별하는 사용자 입력 제목입니다.

- 공식 용어: `목표 이름`
- 코드 표현: `Goal.name`, `goalName`, 일부 UI의 `title`
- 제약: 2자 이상 14자 이하

### 반복 주기

목표를 인증하기로 한 횟수를 계산하는 기간 단위입니다.

- 공식 용어: `반복 주기`
- 코드 표현: `RepeatCycle`
- 값: `매일`, `매주`, `매월`
- API 값: `DAILY`, `WEEKLY`, `MONTHLY`

### 반복 횟수

반복 주기 안에서 목표를 수행하기로 한 횟수입니다.

- 공식 용어: `반복 횟수`
- 코드 표현: `repeatCount`
- 사용 예: `반복 주기를 매주, 반복 횟수를 3회로 설정한다`
- 주의: 실제로 인증한 누적 횟수인 `인증 횟수`와 구분합니다.

### 시작일과 종료일

목표가 유효한 기간의 시작 날짜와 선택적인 종료 날짜입니다.

- 공식 용어: `시작일`, `종료일`
- 코드 표현: `startDate`, `endDate`
- 정책: 종료일은 시작일보다 빠를 수 없습니다.

### 목표 인증 상태

특정 목표 날짜에 나와 짝꿍이 목표를 인증했는지를 나타내는 상태입니다.

- 공식 용어: `목표 인증 상태`
- 코드 표현: `GoalCheckState`, `myCompleted`, `partnerCompleted`
- 값: 아무도 인증하지 않음, 나만 인증함, 짝꿍만 인증함, 둘 다 인증함

### 목표 종료

진행 중인 목표를 더 이상 수행하지 않는 상태로 전환하는 행위입니다.

- 공식 용어: `목표 종료`
- 화면 표현: `끝내기`, `이뤘어요`, `종료`
- 코드 표현: `completeGoal`, `EndGoal`, `StatsStatus.COMPLETED`, `isCompletedGoal`
- 결과: 종료한 목표는 통계의 종료 영역에서 확인합니다.
- 피할 표현: 목표 인증과 혼동되는 `목표 완료`, 같은 상태를 다르게 부르는 `목표 달성`, `이룬 목표`

### 목표 삭제

목표와 그 목표에 저장된 인증샷을 삭제하는 행위입니다.

- 공식 용어: `목표 삭제`
- 코드 표현: `deleteGoal`, `DeleteGoal`
- 사용자 영향: 저장된 인증샷도 함께 삭제

## 날짜

### 목표 날짜

목표의 유효 기간 안에서 날짜별 목표와 그날의 인증 기록을 조회하고 식별하는 기준 날짜입니다.

예를 들어 목표 기간이 6월 11일부터 6월 13일까지라면 6월 11일, 12일, 13일은 각각 별도의 목표 날짜입니다. 사용자는 각 목표 날짜의 목표와 인증샷을 개별적으로 조회하고 인증합니다.

- 공식 용어: `목표 날짜`
- 코드 표현: 홈·목표·인증샷 흐름의 `selectedDate`, `targetDate`, `verificationDate`, `CompletedDate.date`, 일부 Navigation의 `argTargetDate`
- 용도: 날짜별 목표 조회, 인증샷 조회 및 등록, 통계의 인증 기록 조회, 찌르기 쿨타임 식별
- 사용 예: `선택한 목표 날짜의 목표를 조회한다`, `6월 11일 목표 날짜의 인증샷을 6월 12일에 등록한다`
- 피할 표현: `상세 날짜`, `대상 날짜`, `현재 날짜`, `인증 날짜`, `수행 날짜`

### 인증 시간

사용자가 인증샷을 서버에 등록해 목표를 실제로 인증한 시각입니다. 목표 날짜가 지난 뒤에도 인증할 수 있으므로 목표 날짜와 인증 시간의 날짜는 다를 수 있습니다.

- 공식 용어: `인증 시간`
- 코드 표현: `uploadedAt`
- 화면 표현: `방금 전`, `n분 전`, `n시간 전`, `n일 전`
- 사용 예: `6월 11일 목표를 6월 12일 오전 9시에 인증한다`
- 피할 표현: 도메인 행위를 설명할 때 사용하는 `업로드 시간`, `업로드 날짜`
- 주의: 날짜별 기록을 식별하는 `목표 날짜`와 구분합니다.

## 인증샷

### 인증

특정 목표 날짜의 목표를 수행했다는 사실을 기록하는 행위입니다. 목표 날짜가 지난 뒤에도 인증할 수 있습니다.

- 공식 용어: `인증`
- 결과물: 인증샷
- 코드 표현: `myCompleted`, `partnerCompleted`, `GoalVerification`
- 사용 예: `목표를 인증한다`, `이미 인증한 목표다`

### 인증샷

목표 수행을 인증하기 위해 등록한 사진과 코멘트, 리액션을 포함하는 기록입니다.

- 공식 용어: `인증샷`
- 코드 표현: `Photolog`, `PhotoLog`, `GoalVerification`, `PhotologDetail`
- API 표현: `photologs`
- 구성: 이미지, 목표 날짜, 인증한 사용자, 인증 시간, 코멘트, 리액션
- 사용 예: `인증샷을 등록한다`, `짝꿍의 인증샷을 조회한다`

### 인증샷 등록

촬영하거나 선택한 이미지를 특정 목표와 목표 날짜에 연결해 서버에 저장하는 과정입니다.

- 공식 용어: `인증샷 등록`
- 화면 표현: `인증샷 찍기`, `업로드하기`
- 코드 표현: `uploadPhotolog`, `PhotologParam`, `PhotoLogUploadInfo`
- 등록 제약: 한 사용자는 같은 `목표 ID + 목표 날짜`에 인증샷을 최대 하나만 등록할 수 있습니다.
- 사용자별 적용: 같은 목표 날짜에 나와 짝꿍이 각각 인증샷 하나씩 등록할 수 있습니다.
- 처리 단계: 업로드 URL 발급, 이미지 업로드, 인증샷 정보 등록

### 인증샷 수정

기존 인증샷의 이미지 또는 코멘트를 변경하는 행위입니다.

- 공식 용어: `인증샷 수정`
- 코드 표현: `modifyPhotolog`
- 화면 표현: `다시 찍기`, `코멘트 수정`

### 코멘트

인증샷에 작성하는 짧은 문구입니다.

- 공식 용어: `코멘트`
- 코드 표현: `comment`
- 현재 화면 제약: 작성하지 않거나 정확히 5글자로 작성합니다.

### 리액션

짝꿍의 인증샷에 남기는 감정 반응입니다.

- 공식 용어: `리액션`
- 코드 표현: `GoalReactionType`, `reaction`, `reactToPhotolog`
- 사용 예: `짝꿍의 인증샷에 리액션을 남긴다`
- 주의: 목표 자체가 아니라 인증샷에 연결됩니다.

## 찌르기

### 찌르기

아직 목표를 인증하지 않은 짝꿍에게 참여를 독려하는 요청입니다.

- 공식 용어: `찌르기`
- 코드 표현: `Poke`, `pokeGoal`, `PokeGoalUseCase`
- 화면 표현: `찌르기`, `찌르기!`
- 사용 예: `짝꿍을 찌른다`, `찌르기 요청을 보낸다`
- 피할 표현: 리소스 키 오타에서 비롯된 `sting`

### 찌르기 쿨타임

같은 목표와 같은 목표 날짜에 찌르기를 다시 보낼 수 있을 때까지의 대기 시간입니다.

- 공식 용어: `찌르기 쿨타임`
- 코드 표현: `PokeGoalUseCase.COOLDOWN_MS`, `pokeCooldownRemaining`, `PokeHistoryEntity`
- 현재 정책: 3시간
- 식별 기준: `goalId + targetDate`
- 저장 성격: Room에 저장되는 로컬 쿨타임 기록
- 사용 예: `같은 목표라도 목표 날짜가 다르면 찌르기 쿨타임을 별도로 계산한다`

### 찌르기 기록

찌르기 쿨타임을 계산하기 위해 로컬에 저장하는 마지막 찌르기 시각입니다.

- 공식 용어: `찌르기 기록`
- 코드 표현: `PokeHistoryEntity`, `pokedAt`, `poke_history`
- 식별자: 목표 ID와 목표 날짜의 복합키
- 주의: 서버의 영구 활동 이력이 아니라 로컬 쿨타임 캐시입니다.

## 통계

### 조회 기준 월

월별 통계를 조회하기 위해 사용자가 선택한 연월입니다.

- 공식 용어: `통계 조회 기준 월`
- 코드 표현: 통계 흐름의 `selectedDate`, Stats API의 `selectedDate: YearMonth`, `Stats.selectedDate`
- 사용 예: `통계 조회 기준 월을 2026년 6월로 변경한다`
- 주의: 날짜별 목표와 인증 기록을 식별하는 `목표 날짜`와 구분합니다.

### 스탬프 통계

목표별 인증 횟수를 나와 짝꿍의 스탬프로 비교해 보여주는 화면입니다.

- 공식 용어: `스탬프 통계`
- 코드 표현: `Stats`, `StatsGoal`, `ParticipantStats`
- 주요 값: 월간 총 인증 횟수, 인증 횟수, 스탬프 종류, 스탬프 색상

### 월간 총 인증 횟수

해당 목표에 대해 조회 기준 월에 설정된 총 인증 횟수입니다.

- 공식 용어: `월간 총 인증 횟수`
- 코드 표현: `monthlyTargetCount`
- 사용 예: `6월의 월간 총 인증 횟수는 12회다`
- 주의: 사용자가 실제로 인증을 완료한 횟수인 `인증 횟수`와 구분합니다.

### 총 목표 횟수

목표를 생성할 때 설정한 전체 목표 횟수입니다.

- 공식 용어: `총 목표 횟수`
- 코드 표현: `StatsSummary.totalCount`
- 주의: 반복 주기 안에서 설정하는 `반복 횟수`, 실제 인증 결과인 `인증 횟수`와 구분합니다.

### 진행 중 목표와 종료한 목표

통계에서 목표의 수명 주기에 따라 구분하는 두 영역입니다.

- 공식 용어: `진행 중 목표`, `종료한 목표`
- 코드 표현: `StatsStatus.IN_PROGRESS`, `StatsStatus.COMPLETED`

### 인증 횟수

사용자가 목표를 인증한 누적 횟수입니다.

- 공식 용어: `인증 횟수`
- 코드 표현: `completedCount`, API의 `endCount`, `myCompletedCount`, `partnerCompletedCount`

### 목표 날짜별 인증 기록

통계 달력에서 목표 날짜별로 나와 짝꿍의 인증 기록을 나타내는 값입니다.

- 공식 용어: `목표 날짜별 인증 기록`
- 코드 표현: `CompletedDate`, `completedDates`
- 포함 정보: 나와 짝꿍의 인증샷 이미지 URL
- 날짜 필드: `CompletedDate.date`는 `목표 날짜`입니다.

## 알림

### 알림

커플 연결, 찌르기, 목표 인증, 리액션, 목표 종료 등 앱 활동을 사용자에게 전달하는 항목입니다.

- 공식 용어: `알림`
- 코드 표현: `Notification`, `NotificationType`
- 주요 유형: 커플 연결, 찌르기, 목표 인증, 리액션, 일일 목표 인증 완료, 목표 종료
- 상태: 읽음, 읽지 않음
- 관련 행위: 알림 읽음 처리, 전체 읽음 처리

알림 타입별 의미:

| 코드 표현 | 공식 표현 | 발생 조건 |
|---|---|---|
| `PARTNER_CONNECTED` | 커플 연결 알림 | 짝꿍과 연결됐을 때 |
| `POKE` | 찌르기 알림 | 짝꿍이 목표를 찔렀을 때 |
| `GOAL_COMPLETED` | 목표 인증 알림 | 사용자가 인증샷을 등록했을 때 짝꿍에게 전송 |
| `REACTION` | 리액션 알림 | 짝꿍이 인증샷에 리액션을 남겼을 때 |
| `DAILY_GOAL_ACHIEVED` | 일일 목표 인증 완료 알림 | 서버에 타입과 문구만 정의되어 있으며 현재 이벤트 발행과 처리는 구현되지 않음 |
| `GOAL_ENDED` | 목표 종료 알림 | 목표가 종료됐을 때 두 사용자에게 전송 |

### 마케팅 알림

서비스 활동 알림과 별도로 사용자가 선택적으로 동의하는 정보성 알림입니다.

- 공식 용어: `마케팅 알림`, `야간 마케팅 알림`
- 코드 표현: `marketingEnabled`, `nightMarketingEnabled`

## 인증과 계정

### 온보딩

사용자가 로그인 후 서비스 이용에 필요한 정보를 설정하고 짝꿍과 연결하는 과정입니다.

- 공식 용어: `온보딩`
- 코드 표현: `Onboarding`, `PROFILE_SETUP`, `ANNIVERSARY_SETUP`, `COUPLE_CONNECTION`
- 주요 단계: 프로필 설정, 기념일 설정, 커플 연결

### 로그인

Google 또는 Kakao 계정으로 사용자를 인증하고 앱 세션을 시작하는 과정입니다.

- 공식 용어: `로그인`
- 코드 표현: `LoginProvider`, `LoginType`, `AuthRepository.login`
- 로그인 수단: Google, Kakao
- 결과: 성공, 사용자 취소, 실패

### 로그아웃

현재 앱 세션을 종료하되 사용자 데이터와 커플 관계는 유지하는 행위입니다.

- 공식 용어: `로그아웃`
- 코드 표현: `logout`
- 주의: 회원 탈퇴와 구분합니다.

### 회원 탈퇴

계정, 커플 연결, 사용자의 전체 데이터를 삭제하고 복구 불가능한 상태로 만드는 행위입니다.

- 공식 용어: `회원 탈퇴`
- 화면 표현: `탈퇴하기`, `계정 삭제`
- 코드 표현: `withdrawAccount`
- 사용자 영향: 계정 삭제, 커플 연결 해제, 전체 데이터 삭제
- 피할 표현: 로그아웃과 혼동되는 `계정 해제`
- 주의: 현재 독립적인 `커플 연결 해지` 기능은 없습니다. 커플 연결 해제는 회원 탈퇴의 결과입니다.
